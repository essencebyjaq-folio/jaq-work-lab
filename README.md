# JAQ Work Lab

**An interactive training simulation for using AI in everyday office work.**

I built JAQ Work Lab because it’s easier to understand where AI fits when you can try it on work you recognize. Drawing on my experience in business operations, executive support, and employee onboarding, I turned two familiar tasks into a guided practice session. You can see what AI suggests, then decide what you’d keep, change, or flag for review.

[Try the JAQ Work Lab guided demo](https://claude.ai/artifact/Hprbv4KkvDtFWegRkPB6dy)

## Two workflows to try

| Scenario | What you’ll practice |
| --- | --- |
| **Maria’s Inbox** | Prioritize six sample emails, review suggested replies, and change a priority when the AI misses something. |
| **David’s Onboarding Desk** | Turn scattered notes and emails into an onboarding checklist, assign task owners, and review the plan before it’s used. |

## How the demo works

Start with **Guided Demo** and pick a scenario. Each walkthrough takes you from the original task to an AI-assisted result, then asks you to review the output and consider where it helps. Guided Demo uses fictional data and predefined results. You can use it without a Claude account. Optional **Live AI** requires Claude access.

I designed the **Human Review** step into both workflows because a draft reply still needs context, and an onboarding plan still needs someone to confirm who owns each task.
